## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando las siguientes herramientas y tecnologías:

*   **HTML5 / CSS3:** Estructura semántica y diseño estilizado a medida.
*   **JavaScript (ES6+):** Interactividad, animaciones y lógica del sitio.
*   **Git & GitHub:** Control de versiones y alojamiento del código.
*   *Nota: Si utilizaste frameworks como React, Angular, Vue o Tailwind CSS, añádelos a esta lista.*

## ✨ Características Principales

*   **Diseño Totalmente Responsivo:** Adaptado perfectamente para dispositivos móviles, tablets y computadoras de escritorio.
*   **Sección Sobre Mí:** Un resumen de quién soy, mis metas y qué me apasiona del desarrollo.
*   **Sección de Experiencia:** Detalle de mi trayectoria profesional (incluyendo mi experiencia en Jumbo S.A.S. y otros roles relevantes).
*   **Galería de Proyectos:** Vitrina interactiva con enlaces a los códigos fuente y demostraciones en vivo de mis trabajos.
*   **Formulario de Contacto:** Canal directo para que reclutadores o clientes puedan comunicarse conmigo.
